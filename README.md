# BeautyOne - RWD 品牌形象網站
🔗 Demo（GitHub Pages）：https://evelllyn.github.io/beautyonerwd/

BeautyOne 是一個以 HTML + SCSS 製作的美妝保養品牌形象網站，著重於 網頁切版、RWD 響應式設計、CSS Layout 與視覺動畫，並透過 SCSS 管理樣式與共用變數，
練習從 Desktop、Tablet 到 Mobile 的版面配置，以及不同裝置下的操作方式與互動設計。

專案特色：

- RWD 響應式網頁設計
- 使用 Flexbox、CSS Grid 進行版面配置
- 使用 clamp() 製作響應式字體與間距
- SCSS 模組化樣式管理
- CSS Animation / Transition / Transform
- 響應式導覽列與漢堡選單
- 商品分類子選單與搜尋欄互動
- Sticky / Fixed 定位效果
- Carousel 橫向滑動效果
- JavaScript DOM 互動

---

## RWD 與互動設計

### Desktop

- 水平導覽列，商品分類以 Hover 顯示子選單
- Grid / Flexbox / clamp() 調整版面配置

### Tablet / Mobile

- 改用漢堡選單，以 Click 操作導覽列與子選單
- 搜尋功能改為點擊搜尋圖示後展開
- 依螢幕尺寸調整字體、間距與圖片排列
